🔗1. Ethernet

Ethernet is the dominant technology used for communication inside a Local Area Network (LAN). Devices communicate using Ethernet frames.

PC -------- Switch -------- Server A simplified Ethernet frame contains: Destination MAC Source MAC Data
📌
Ethernet operates at Layer 2 (Data Link) of the OSI model. It defines how devices format and transmit data on the local network segment.

🔗2. MAC Address

MAC = Media Access Control. A MAC address is a Layer 2 address associated with a network interface.

🔗
Format
00:1A:2B:3C:4D:5E

• 48 bits total
• 6 bytes
• Written in hexadecimal
• 6 groups of 2 hex digits
📚
Purpose
Identifies a network interface at Layer 2.

Used for local frame delivery on the Ethernet segment. Not routable across subnets.
