🔗1. MAC Address vs IP Address

A device can have both a MAC address and an IP address at the same time — they operate at different OSI layers.

🔗
MAC Address
Layer 2 — Data Link
Hardware identifier burned into the NIC.
e.g. AA:BB:CC:11:22:33
Used on the local network.
🌎
IP Address
Layer 3 — Network
Logical addressing assigned by config/DHCP.
e.g. 192.168.1.10
Used for end-to-end routing.
