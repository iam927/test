🌐1. VLAN Review

A VLAN logically divides a physical switch into multiple separate Layer-2 broadcast domains. Devices in different VLANs cannot communicate at Layer 2 without routing.

🔌 Without VLANs

SWITCH / | \ PC1 PC2 PC3 All in one broadcast domain

✅ With VLANs

SWITCH / \ VLAN 10 VLAN 20 / \ / \ PC1 PC2 PC3 PC4 Employees IT
🎓
Key definition: A VLAN provides logical Layer-2 network separation. One physical switch → multiple logical networks.

🔌2. Access Port

An access port normally belongs to one VLAN and is used to connect end devices.

💻
Common Devices
• PC / Laptop
• Printer
• Camera
• Server
• IP Phone
• Any endpoint
🔌
How It Works
The switch places all traffic arriving on this port into the assigned VLAN. The end device is unaware of VLAN tagging.
Configure Access Port (Cisco)
interface fa0/1 switchport mode access switchport access vlan 10
🎓
Memorize: Access port → normally one VLAN

🔄3. Trunk Port

A trunk port carries traffic for multiple VLANs over one physical link. Used between network devices.

TRUNK SW1 =================== SW2 VLAN 10 VLAN 20 VLAN 30
🔌
Common Trunk Connections
• Switch ↔ Switch
• Switch ↔ Router
• Switch ↔ L3 device
• Switch ↔ certain APs
🔄
Why Trunk?
Instead of one physical link per VLAN, a single trunk carries all VLANs. More efficient and scalable.
Configure Trunk Port (Cisco)
interface g0/1 switchport mode trunk
🎓
Memorize: Trunk → multiple VLANs

🔁4. Access vs Trunk Port

FeatureAccess PortTrunk Port
VLANsNormally oneMultiple
Typical useEnd devices (PC, printer)Network device connections
VLAN taggingNot toward endpoint802.1Q tag identifies VLAN
ExamplePC → SwitchSwitch ↔ Switch or Router
🎓
Simple memory rule:
ACCESS = ONE VLAN
TRUNK = MANY VLANs

📋5. 802.1Q VLAN Tagging

IEEE 802.1Q is the standard used for VLAN identification on Ethernet trunk links. A 4-byte VLAN tag is inserted into the Ethernet frame:

Standard Frame: [ Dest MAC ][ Src MAC ][ Data ] 802.1Q Tagged Frame: [ Dest MAC ][ Src MAC ][ 802.1Q Tag ][ Data ] | VLAN ID (e.g. 10, 20, 30)
📌
The VLAN tag tells the receiving switch or router which VLAN the frame belongs to. Without tagging, a trunk link cannot carry multiple VLANs.

🏠6. Native VLAN

The native VLAN is the VLAN whose traffic is normally sent untagged on an 802.1Q trunk.

SW1 =================== SW2 TRUNK Native VLAN 99 - Tagged traffic: VLANs 10, 20, 30 - Untagged traffic: VLAN 99 (native)
⚠
Production tip: Cisco defaults native VLAN to VLAN 1. Many network designs change the native VLAN as a security practice. The native VLAN must match on both ends of the trunk or mismatches occur.

🔁7. Inter-VLAN Routing

A Layer-2 switch cannot route traffic between different VLANs. You need a Layer-3 device.

🚫 Layer-2 Switch Alone

VLAN 10 and VLAN 20 are separate broadcast domains. Traffic between them is blocked at Layer 2. A ping from VLAN 10 to VLAN 20 will fail.

✅ With Layer-3 Device

A router or L3 switch routes between the VLANs using IP routing. Traffic can now flow between VLAN 10 (192.168.10.0/24) and VLAN 20 (192.168.20.0/24).

🎓
Interview answer: "A normal Layer-2 switch forwards Ethernet frames using MAC addresses and does not perform IP routing between different networks. A Layer-3 device is required for inter-VLAN routing."

🏠8. Default Gateway

A default gateway is the device a host sends traffic to when the destination is outside its local subnet.

PC1 Configuration: IP Address: 192.168.10.10 Subnet Mask: 255.255.255.0 Default Gateway: 192.168.10.1 PC1 wants to reach: 192.168.20.10 192.168.20.10 is NOT in 192.168.10.0/24 Therefore PC1 sends to gateway: 192.168.10.1
📌
Each VLAN/subnet needs its own gateway address configured on the Layer-3 device. VLAN 10 → 192.168.10.1, VLAN 20 → 192.168.20.1.

🔄9. Router-on-a-Stick

Router-on-a-Stick is a method of inter-VLAN routing using one physical router interface with multiple logical subinterfaces.

🔄 ROUTER (G0/0)
G0/0.10 → VLAN 10
192.168.10.1
G0/0.20 → VLAN 20
192.168.20.1
TRUNK (802.1Q)
🔌 SWITCH
VLAN 10
PC1
192.168.10.10
VLAN 20
PC2
192.168.20.10
📌
Router-on-a-Stick is called "on a stick" because the router connects to the switch via a single trunk link — one physical interface handling all VLANs.

🔌10. Router Subinterface Configuration

Step 1 — Enable physical interface
interface g0/0 no shutdown
Step 2 — Subinterface for VLAN 10
interface g0/0.10 encapsulation dot1Q 10 ip address 192.168.10.1 255.255.255.0
Step 3 — Subinterface for VLAN 20
interface g0/0.20 encapsulation dot1Q 20 ip address 192.168.20.1 255.255.255.0
Step 4 — Switch trunk toward router
interface g0/1 switchport mode trunk
Verify router interfaces
show ip interface brief
🎓
Key command: encapsulation dot1Q 10 — associates the subinterface with VLAN 10 using 802.1Q tagging. This is essential for Router-on-a-Stick.

🔌12. Cisco Show Commands

Check VLANs and access port assignments
show vlan brief
Check trunk ports and allowed VLANs
show interfaces trunk
Check MAC address table
show mac address-table
Check port status, speed, duplex, VLAN
show interfaces status
Check router interface IP and status
show ip interface brief
Check active configuration
show running-config

🔧13. Troubleshooting Inter-VLAN

If VLAN 10 PC → VLAN 20 PC fails, check in this order:

1. PC IP / mask / gateway correct?
ipconfig
↓
2. Correct VLAN on PC port?
show vlan brief
↓
3. Access port configured?
show interfaces status
↓
4. Trunk operational?
show interfaces trunk
↓
5. VLAN allowed on trunk?
show interfaces trunk
↓
6. Router subinterfaces up?
show ip interface brief
↓
7. Routing table correct?
show ip route
⚠
Common mistakes: Wrong VLAN on access port • Native VLAN mismatch • Incorrect gateway configured on PC • VLAN not allowed on trunk • encapsulation dot1Q VLAN ID mismatch on subinterface
