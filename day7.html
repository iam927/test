🌐1. VLAN Communication

A VLAN creates a separate Layer-2 broadcast domain. Devices in different VLANs and different IP subnets require a Layer-3 device to communicate.

VLAN 10 / 192.168.10.0/24 VLAN 20 / 192.168.20.0/24 | | PC1 PC2 Layer-2 switch alone: PC1 cannot reach PC2 Layer-3 device required: Inter-VLAN Routing

🔌3. Creating VLANs (Switch)

🔌 Switch Configuration — Create VLANs
vlan 10 name USERS vlan 20 name IT
Verify
show vlan brief
📌
VLANs must be created before they can be assigned to ports. show vlan brief confirms the VLAN exists and shows which ports are assigned to it.

🔌4. Configuring Access Ports (Switch)

🔌 Switch Configuration — Access Ports
! PC1 connected to Fa0/1 interface fa0/1 switchport mode access switchport access vlan 10 ! PC2 connected to Fa0/2 interface fa0/2 switchport mode access switchport access vlan 20
Verify access port assignments
show vlan brief

PC1 is now in VLAN 10. PC2 is now in VLAN 20. They are in separate broadcast domains.

🔄5. Configuring the Trunk (Switch)

The switch port connected to the router must be a trunk to carry multiple VLANs.

🔌 Switch Configuration — Trunk to Router
! Router connected to G0/1 interface g0/1 switchport mode trunk
Verify trunk
show interfaces trunk
ROUTER | | TRUNK (G0/1 on Switch) | SWITCH / \ VLAN 10 VLAN 20

🔄6. Router-on-a-Stick Overview

One physical router interface (G0/0) with two logical subinterfaces handles routing for both VLANs.

ROUTER G0/0 | +-- G0/0.10 --> encapsulation dot1Q 10 --> 192.168.10.1 | +-- G0/0.20 --> encapsulation dot1Q 20 --> 192.168.20.1 | | TRUNK | SWITCH / \ VLAN10 VLAN20 | | PC1 PC2
